# M06_S04 · App Store sandbox spike：两档能力决策

## OKR

- **Objective**：用两周换一个不再悬置的答案——MAS 通道 go 或 no-go，每项能力的存亡都有实测证据，且无论结论如何直发通道分毫不受拖累。
- KR1：书面 go/no-go 建议落库，逐能力实测证据齐备。
- KR2：sandbox 原型对丢失 cell 渲染标注"App Store 构建中不可用"状态。
- KR3：限时守住：spike 期间直发分发工作零受影响。
