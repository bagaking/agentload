# App Store Positioning

This page defines the public positioning for an App Store or notarized release.

## Product Frame

Agent Load is a local macOS developer utility for people running multiple AI
coding agents. It shows local session activity, process pressure, and project
load so the user can understand what is active on their own Mac.

## Audience

- developers using AI coding tools locally
- power users who run multiple agent sessions
- people who want a compact menu bar view of current local agent activity

## Primary Value

- see current local AI coding load
- separate active sessions from idle sessions
- understand process pressure and mapped sessions
- inspect recent project activity without opening each tool
- keep all observed activity data local by default

## Message Pillars

Local:

- Runs on your Mac.
- Uses local evidence.
- No cloud upload of observed activity data.

Developer focused:

- Built for AI coding sessions.
- Helps interpret multiple local agents and subprocesses.
- Shows process pressure, freshness, and project load.

Transparent:

- Best-effort mapping is shown as evidence, not certainty.
- Resource usage and token totals are labeled as local observations.
- Unmatched processes remain visible instead of hidden.

## Avoided Positioning

Do not describe Agent Load as:

- employee monitoring
- workplace surveillance
- security compliance
- secret background auditing
- guaranteed attribution
- cloud AI analysis

## Draft Metadata

Name:

Agent Load

Subtitle:

Local AI coding activity monitor

Short description:

Monitor local AI coding sessions, process pressure, and project activity from
your Mac menu bar.

Long description draft:

Agent Load helps developers understand local AI coding activity on their own
Mac. It maps visible AI coding processes to local session evidence when
available, shows which sessions are active or idle, and summarizes project load
and process pressure from a compact menu bar dashboard.

Agent Load is designed as a local utility. Observed activity data is processed
on device, and the app does not upload your session metadata, process commands,
token totals, or project names.

## Review Note Draft

Agent Load is a local developer tool for observing AI coding activity on the
user's own Mac. It reads local process/resource information and local tool
evidence to present session freshness, process pressure, and project activity.
The app does not include advertising, analytics SDKs, tracking, cloud sync, or
third-party AI processing. The embedded dashboard is served over loopback for
the menu bar UI.

If submitted as a sandboxed Mac App Store build, process and local file access
must be limited to permitted system visibility and explicit user-selected
evidence folders.
