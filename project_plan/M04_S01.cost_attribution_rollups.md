# M04_S01 · 成本归因与归集：锁版本价格表

## OKR

- **Objective**：把"哪个项目/会话/subagent 在花我的钱"变成可追溯的证据链——每个成本数字都能报出它的 token 来源与价格表版本。
- KR1：fork 会话 fixture 上 subagent 归因与 ground truth 一致，零重复计数（直击 ccusage #897/#313 的品类顽疾）。
- KR2：UI 审计测试证明 100% 成本数字带"估算——非账单事实"标签与价格表版本号。
- KR3：语义层 guard 确认成本算术零泄漏到语义层之外。

## Checklist

- [ ] 内置带版本号的本地价格表；UI 显示表版本；文档化更新路径

- [ ] 构建项目 / 会话 / subagent 三级归集，利用既有证据式角色推断避免 fork 重复计数

- [ ] 全部成本表面三语本地化

## 验收标准（量化）

1. subagent 归因在 fixture 上与 ground truth 一致；fork fixture 零重复计数。
2. UI 审计测试：每个成本数字显示估算标签 + 价格表版本。
3. 无 token 证据的 vendor 渲染标注空缺，绝非 $0。
4. 语义层 guard（M01_S02 建立）确认语义层之外无成本算术。
