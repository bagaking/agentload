# M02_S03 · Vendor 第一波 a：opencode 全证据 adapter

## OKR

- **Objective**：opencode 在证据存在处全量可见、在证据缺失处诚实标注，同时实测 adapter 抽象的接入成本。
- KR1：opencode 的会话/角色/token 在有证据处全部可见，每个点亮的矩阵 cell 有夹具测试背书。
- KR2：变更面收敛在其 adapter 包 + 注册（包外 ≤200 LOC，目标 0）。
- KR3：损坏夹具测试证明降级路径生效——出错时降 cell 层级而非输出错误数字。

## Checklist

- [ ] 添加 opencode transcript 根目录 + 工具原生 env fallback，只触碰其 adapter 包
- [ ] 用真实 transcript 采集 golden 夹具，解析 opencode 会话/角色/token 证据
- [ ] 映射、角色推断、recent-movement 全部经既有语义层路由
- [ ] 覆盖矩阵 cell 按诚实层级点亮；解析不了的信号保持标注空缺
- [ ] 实现解析异常降级路径：损坏输入 → cell 层级下调，而非发出数字
- [ ] 增加 per-tool coverage rail 条目、工具图标与三语字符串
- [ ] 记录实际 LOC 与日历耗时，作为 adapter 接入成本基准

## 验收标准（量化）

1. opencode 会话、角色、token 在证据存在的一切位置可见；每个点亮 cell 有夹具测试。
2. adapter 变更面限于自身包 + 注册（包外 ≤200 LOC，目标为零）。
3. 损坏夹具测试证明层级降级而非错误数字（**anti-ccusage-#950 门**：加了但错，比没加更糟）。
4. 一个日历周内完成；否则按计划偏差规则记录偏差并建重构跟进（Mini-Sprint）。
