# M05_S04 · consent-gated hooks 安装器与 loopback OTLP

## OKR

- **Objective**：在用户逐字看到变更并可一键撤销的前提下，把 Claude Code 的 attention 与用量信号升级到 ground truth——同意是升级的唯一通道，隐私不变式分毫不动。
- KR1：无 diff 展示的同意绝不写入 hooks；回退把 settings.json 恢复到逐字节一致（测试）。
- KR2：hook 派生状态标注 ground truth、transcript 派生标注 inferred——UI 中可见地区分。
- KR3：网络审计测试：OTLP 接收器仅绑 loopback，零外发连接。

## Checklist

- [ ] 构建 hooks 安装器：写入前展示确切 settings.json diff、一键回退、绝不捆入 onboarding 默认（不是静默注入，是明白同意——观察者写入被观察者配置必须如此）
- [ ] 经本地 JSONL 文件（agentload tail 之）摄入 hook 事件：Notification permission_prompt / idle_prompt、Stop / SubagentStop；attention 状态升至 ground-truth 档
- [ ] 实现仅 loopback 的 OTLP 接收器，填上 runtime_telemetry.go 预留 seam，状态从 "not_configured" 升级为诚实的 "configured"；本地脱敏 user.email
- [ ] OTel GenAI semconv 命名隔离在钉版本的映射层后（spec pre-1.0 且 2026-06 迁库中，直接引用即背上漂移债）
- [ ] 覆盖矩阵为 Claude Code 增加 consented 档；其他 vendor 的 cell 诚实留空
- [ ] Preferences 中呈现 consent 状态；全部 consent 文案三语本地化

## 验收标准（量化）

1. hooks 无 diff 展示同意绝不写入；回退恢复 settings.json 逐字节一致（测试）。
2. hook 派生状态标 ground truth、transcript 派生标 inferred，UI 可见区分（M03_S01 保真度标签体系的兑现）。
3. 网络审计测试：OTLP 仅 loopback，零外发连接（隐私不变式回归）。
4. 矩阵在 opt-in 时立即反映 consented 档、opt-out 时立即降档。
