# M03_S02 · Needs-you triage 面、菜单栏 glyph、tray i18n 对齐

## OKR

- **Objective**：菜单栏与 popover 回答第一问题"哪个会话需要我"，且原生层达到 web 层同等的诚实与三语标准。
- KR1：needs-you 状态转移在一个事件 tick 内反映到菜单栏。
- KR2：tray 字符串 100% 纳入 locale 校验器，en/zh/ja 齐备。
- KR3：VoiceOver（VO-M-M）对 status item 有意义播报；glyph 在明暗/icon-only/刘海屏均正确渲染。

## Checklist

- [ ] popover fleet 视图从按新旧排序改为按 needs-you 排序；信息密度按 ~5 并发会话调优并优雅溢出
- [ ] 构建原生菜单栏层：template-image 状态 glyph + needs-you 计数——栏内只放一个有意义的值
- [ ] 增加 icon-only 模式与用户可调宽度，适配刘海屏
- [ ] 增加右键上下文菜单（Open Dashboard / Refresh / Pause / Quit）与 status item accessibility label
- [ ] tray/原生壳全部字符串（现 tray.go 硬编码英文）路由进 locale 文件，由 scripts/validate_locales.js 强制
- [ ] glyph 颜色仅在有意义的状态转移时变化；原生栏独立于 web 层保持真实
- [ ] 优雅处理 status item 被移除（removalAllowed + KVO）

## 验收标准（量化）

1. 菜单栏在一个事件 tick 内反映 needs-you 转移。
2. tray 字符串 100% 被 locale 校验器覆盖，三语齐备。
3. VoiceOver 有意义播报 status item（VO-M-M 审计通过）。
4. glyph 在 light/dark 与 icon-only 模式、刘海屏上渲染正确。
