# M06_S03 · 每日 review digest 与用户侧导出

## OKR

- **Objective**：把"下班前/早晨第一眼"变成一屏——谁完成了待 review、谁花了多少、谁有摩擦，排序全部可追溯到既有证据，不加一个新判断。
- KR1：fixture 日在 <1s 内从既有 history 渲染完成，零新增轮询。
- KR2：导出审计零绝对路径/prompt/命令参数（沿用成文省略清单）。
- KR3：排序仅可追溯到 attention 状态与成本归集（审计）。

## Checklist

- [ ] 构建"我的 agents 今天干了什么"表面：从 JSONL history 与 transcript 证据生成会话级时间线，按 finished-awaiting-review 状态、成本、观测摩擦线索排序
- [ ] 排序严格来自既有 attention 状态与成本归集——零新启发式、不评分产出、不做 diff review（评分与 review 属编排器/eval 疆界，PLAN §7 已否决）
- [ ] history 与 digest 的 Markdown/CSV/JSON 导出：与消毒诊断导出分立，但共用同一路径消毒规则
- [ ] digest 与导出表面三语本地化

## 验收标准（量化）

1. fixture 日 <1s 从既有 history 渲染，零新增轮询（M02_S02 预算不动）。
2. 导出审计测试：无绝对路径、prompt、命令参数——对照成文省略清单。
3. 排序仅可追溯到 attention 状态与成本归集（审计——digest 不得夹带未成文的"重要性"判断）。
4. 全部文案 en/zh/ja。
