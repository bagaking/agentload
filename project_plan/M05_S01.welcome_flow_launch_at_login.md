# M05_S01 · 60 秒欢迎流程与 opt-in 登录启动

## OKR

- **Objective**：从全新安装到有用的 popover 不超过 60 秒、不碰任何设置、不弹任何非用户发起的权限请求。
- KR1：计时测试：全新安装 → 有数据的 popover <60s，零配置。
- KR2：无显式勾选零登录项注册（经 Ventura 后台项行为验证）。
- KR3：locale 校验器覆盖整个流程，三语齐备。

## Checklist

- [ ] 构建首启欢迎窗口：60 秒内到达有用的 popover、零设置（config.go 的 CLAUDE_CONFIG_DIR/CODEX_HOME/TRAE_CLI_HOME tool-native 回退已让默认值即可用）
- [ ] SMAppService 登录启动：opt-in、默认关、欢迎页解释——绝不静默注册（当前仓库无任何 SMAppService 代码，从零实现）
- [ ] 通知权限请求延迟到用户创建第一条规则时（衔接 M03_S04 的零默认通知）
- [ ] 把 M03/M04 各设置合并进持久化本地设置文件（M05_S02 的 Preferences 将管理同一文件）
- [ ] onboarding 中提供全局快捷键设置（Raycast 模式——快捷键录制器在欢迎流程内，不埋进偏好设置）
- [ ] 整个流程 en/zh/ja 本地化

## 验收标准（量化）

1. 计时测试：全新安装 → 有数据的 popover <60s，无任何配置操作。
2. 无显式开关不注册登录项（Ventura 后台项通知行为验证——静默注册是信任杀手）。
3. onboarding 期间除用户发起外零权限弹窗。
4. locale 校验器覆盖全流程字符串。
