# M03_S03 · 一键动作：跳转 / 检查 / resume / 显式停止

## OKR

- **Objective**：从"看见需要我"到"到达现场"只隔一次按键，且任何进程干预都由人显式发起。
- KR1：任何浮出的会话 ≤1 次按键/点击可达（宿主窗口聚焦），在 claude/codex/trae 宿主上验证。
- KR2：代码审计 + 测试证明零自动进程信号；停止永远要求显式确认。
- KR3：动作包在 sandbox 构建 flag 下干净地编译剔除。

## Checklist

- [ ] 逐会话动作：经既有宿主祖先证据聚焦确切的终端/IDE 窗口，扩展 open-host-app endpoint
- [ ] 打开会话检查器与复制 resume 命令动作（resume 是已被验证的 workflow hook）
- [ ] 显式停止：SIGINT/SIGTERM 置于确认对话框之后——仅限用户发起、绝不自动；隔离在独立包内，使 sandbox-safe 构建可整包剔除
- [ ] 全局热键切换 popover，配冲突检测录制器
- [ ] Esc 恒关闭；popover 会话树全键盘导航
- [ ] 定义通知（M03_S04）将用于聚焦会话的 deep-link scheme
- [ ] 全部动作字符串三语本地化

## 验收标准（量化）

1. 任何浮出的会话 ≤1 次按键/点击到达宿主窗口，claude/codex/trae 宿主逐一验证。
2. 代码审计 + 测试：零自动进程信号；停止必经显式确认（中立观测者立场的行为红线）。
3. 热键冲突在注册时检测并呈现。
4. 动作包在 sandbox 构建 flag 下编译剔除干净。
