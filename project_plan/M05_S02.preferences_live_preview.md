# M05_S02 · 偏好设置：live preview、导入导出、a11y

## OKR

- **Objective**：每个选项所见即所得、每个开销有公示、每个设置可带走——偏好面成为信任表面而非开关堆。
- KR1：live preview 与实际菜单栏渲染在全部选项组合下一致（snapshot 测试）。
- KR2：设置跨重启存活 + 导出/导入无损往返。
- KR3：偏好面与 popover 键盘全遍历，VoiceOver 审计通过。

## Checklist

- [ ] 构建 Preferences 表面：glyph/宽度/icon-only 选项变化时菜单栏项 live preview（iStat 招牌模式）
- [ ] 给 M02_S02 的按模块开关一个人类界面：每个开关旁展示已公示的成本注记（Stats 式诚实成本，但组织有序）
- [ ] 刷新节拍控制：暴露并强制 30s 下限（下限是产品级观测边界，UI 不许绕过）
- [ ] 通知规则编辑器从最小版（M03_S04）升级为完整管理
- [ ] 实现设置导出/导入（iStat 用户点名喜爱的功能）
- [ ] 完成 M03 起步的键盘/VoiceOver 全通：偏好面与 popover 全遍历

## 验收标准（量化）

1. live preview 与实际菜单栏渲染在所有选项组合下一致（snapshot 测试）。
2. 设置跨重启存活且导出/导入无损往返（回归测试——不持久的设置是品类成文卸载触发器，见 M03_S04 验收 2）。
3. 节拍控制无法设到 30s 以下（强制 + 测试）。
4. 偏好面与 popover 完整键盘遍历；VoiceOver 审计通过（衔接 M03_S02 的状态项 a11y 标签）。
