# M02_S01 · 证据覆盖矩阵：UI / API / 文档三端同源

## OKR

- **Objective**：把"诚实分级"从文档原则变成可执行的机器事实——任何能力变化在三端零手工同步。
- KR1：改一处 adapter 能力声明，API、UI 面板、文档页三端同步更新（测试证明零手工编辑）。
- KR2：100% 渲染的 snapshot 数据可追溯到某个矩阵 cell 及其命名的证据来源。
- KR3：审计测试证明未观测 cell 渲染为带标注的空缺——绝无零值、估算或推断的假对等。

## Checklist

- [ ] 从 M01_S02 的 adapter 能力声明生成 vendor × 信号族矩阵（信号族：presence/resources、sessions/roles、recent movement、tokens/cost、quota windows、workspace context、consented telemetry）
- [ ] 定义 cell 状态：observed / partial / unavailable / not_configured，每态命名其证据来源——延伸既有诚实能力模式（thermal 的 "unavailable"、telemetry 的 "not_configured"）
- [ ] 矩阵以 /api endpoint 提供，dashboard 面板从同一生成源渲染（SSOT）
- [ ] 文档页从同一源生成，使 docs、API、UI 无法漂移
- [ ] 所有 cell 标签经 metric_semantics.go 与 ui/src/lib/metricSemantics.ts 路由
- [ ] 每个 cell 状态与信号族补齐 en/zh/ja 字符串
- [ ] 把矩阵确立为发布门：vendor 以其 cells 诚实支撑的层级发布，不多不少

## 验收标准（量化）

1. 修改一处 adapter 能力声明 → API、UI 面板、文档零手工编辑同步更新（测试证明）。
2. 100% 已渲染 snapshot 数据可追溯到矩阵 cell 与命名证据来源。
3. 审计测试：未观测 cell 渲染为标注空缺，绝非零值/估算/推断对等。
4. locale 校验器绿，全部新 key 三语齐备。
