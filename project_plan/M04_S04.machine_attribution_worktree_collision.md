# M04_S04 · 机器影响归因与 worktree 冲突信号

## OKR

- **Objective**：回答品类里没人回答的问题——"机器烫是不是 agent 干的、是哪个、哪个项目"，两次点击内从菜单栏到达答案。
- KR1：从菜单栏出发，最高资源消耗者的 PID → 会话 → 项目归因 ≤2 次点击可达。
- KR2：冲突 fixture（两会话一 worktree）以成文标准文案浮出信号。
- KR3：perf gate 绿——本视图零新增轮询（纯组合）。

## 验收标准（量化）

1. 菜单栏 → 最高资源消耗者的 PID→会话→项目归因，≤2 次点击（对照 DOCREF_004 第 6 条的归因 job）。
2. 冲突 fixture 浮出信号且文案有成文标准出处（中立描述"观测到共享 worktree"，不判断对错）。
3. sandbox 变体构建渲染标注 unavailable 态而非空白（compile-flag 测试）。
4. perf gate 绿——视图零新增轮询（M02_S02 预算不动）。
