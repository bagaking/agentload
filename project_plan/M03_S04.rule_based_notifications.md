# M03_S04 · 规则式本地通知与严格礼仪

## OKR

- **Objective**：通知系统上线且一条烦人通知都不存在——零默认、可解释、可深链、前台抑制。
- KR1：浸泡测试：全新安装、无规则 → 零通知。
- KR2：规则跨重启持久化（回归测试锁定）。
- KR3：从 popover 关闭状态点击通知能聚焦到正确会话。

## Checklist

- [ ] 集成 UNUserNotification，默认零启用告警——通知只为用户创建的规则存在
- [ ] 规则类型 v1：会话完成待 review；等待 permission/input 超 N 分钟；needs-you 计数超 N（看门狗规则在 M04_S03 加入）
- [ ] dashboard 设置面板内构建最小规则编辑器；规则持久化到本地设置文件
- [ ] 通知点击经 M03_S03 的 deep-link scheme 深链到会话
- [ ] focus-aware 抑制：相关宿主 app 在前台时不通知
- [ ] 每条通知正文显示触发规则与阈值；全部文案三语本地化

## 验收标准（量化）

1. 浸泡测试：全新安装无规则 → 零通知。
2. 规则跨重启持久（回归测试——通知设置不持久是品类成文的卸载触发器）。
3. 通知点击从关闭的 popover 聚焦正确会话。
4. 每条通知自报其规则与阈值，三语齐备。
